# 答题页版式与倒计时调整设计说明

> 状态：待实现
> 日期：2026-05-04

## 目标

对当前答题页做一轮体验增强，包含四项调整：

- 固定题目正文区域的框体尺寸
- 让四个选项内容统一左对齐
- 将主操作按钮移到右侧，并把文案改成 `Suivant`
- 在页面右侧显示剩余答题时间，每套题总时长为 60 分钟
- 刷新页面后恢复当前浏览器中的本地草稿答案

同时，倒计时必须符合正式考试场景：

- 不是仅在当前页面打开期间计时
- 而是按本次练习的开始时间持续计算剩余时间
- 页面刷新后，剩余时间仍然准确
- 页面刷新后，当前浏览器里的草稿答案仍然准确回填
- 用户提交成功后，不再继续倒计时
- 如果时间耗尽，应自动提交当前答题结果

## 用户需求

当前答题页已经具备左侧题号导航与自由跳题能力，但在实际做题体验上还存在几个问题：

- 阅读区高度会随不同题目变化，切题时页面节奏不稳
- 阅读区宽度仍然偏窄，长段材料阅读压力偏大
- 选项块虽然已经可点击，但内容视觉上还不够像标准考试选项列表
- 主操作按钮停留在左侧，不符合“做完当前题继续向后”的视觉动线
- 没有剩余时间展示，缺少正式考试的节奏感
- 页面刷新后，已经做过的题虽然能回到题目，但草稿答案没有一起恢复

因此这次不是新增新业务流程，而是在现有答题页上增强“稳定性、方向感、考试感”。

## 设计结论

本次采用下面这套方案：

- 左侧继续保留题号导航
- 中间保留当前题正文与选项区，并明显放大正文宽度
- 右侧增加考试信息区，其中最重要的是 60 分钟倒计时
- 题目正文区使用固定高度，并在内容超长时通过内部滚动查看
- 四个选项保持整块可点击，但文本和标识统一靠左排列
- 主操作按钮放在当前答题区右下角，并改成 `Suivant`
- 若已经到最后一题，则按钮仍切换成提交语义，不强行保持 `Suivant`
- 当前浏览器中的本地草稿答案会随刷新一起恢复

## 页面结构

答题页调整为三段式桌面布局：

- 左侧：题号导航
- 中间：当前题答题区（主视觉宽区）
- 右侧：考试信息区

右侧考试信息区包含：

- 剩余时间卡片
- 本套题题数摘要
- 当前进度摘要

移动端不强行保留三栏：

- 题号导航仍然折叠到正文上方
- 倒计时信息区移动到正文上方或下方
- 保证正文优先，不挤压阅读区域

## 正文区设计

### 1. 固定题目正文框大小

这里的“固定”在本次中采用更明确的规则：

- 正文卡片使用固定高度
- 不再因为材料长短改变外层高度
- 当内容超出卡片高度时，在卡片内部出现纵向滚动条
- 页面整体高度保持稳定，阅读区域单独滚动

这样可以兼顾：

- 视觉稳定
- 不挤压右侧信息卡
- 不让短题和长题切换时页面跳跃过大
- 不截断阅读材料，只改变查看方式

### 2. 选项统一左对齐

当前选项块保留整块按钮交互，但样式改成更标准的考试阅读习惯：

- 选项字母在左
- 选项文本紧随其后
- 整块内容从左往右阅读
- 不做居中排版

选项内部需要保持：

- 清晰的层级
- 稳定的行高
- 选中态仍然突出

## 主操作按钮设计

按钮改动规则如下：

- 非最后一题时，主按钮文案改成 `Suivant`
- 按钮放到当前题面板的右下角
- 视觉上形成“继续往后”的动作方向
- 最后一题时仍保留提交逻辑，文案使用当前提交语义

这里不把所有阶段都改成法语，是为了避免最后一题出现“继续”与“提交”语义冲突。

## 倒计时设计

### 1. 总时长

- 每套题总时长固定为 60 分钟

### 2. 计时基准

倒计时必须基于“本次练习开始时间”来计算，而不是页面打开时长。

这意味着：

- 页面首次进入答题页时，记录该 session 的开始时间
- 后续每秒根据 `当前时间 - 开始时间` 计算已用时
- 再从 60 分钟里扣除，得到剩余时间

### 3. 刷新后的连续性

如果用户刷新页面：

- 不能重新从 60:00 开始
- 必须继续沿用这次练习原本的开始时间

因此开始时间需要在前端会话状态里保存，并且能在刷新后恢复。

### 4. 提交后的停止条件

一旦用户提交成功：

- 本次 session 结束
- 页面跳转到结果页
- 倒计时不再继续显示，也不再继续运行

### 5. 时间耗尽

当剩余时间归零时：

- 自动保存当前题已选答案
- 自动触发整套答案提交
- 防止用户在时间耗尽后继续作答

## 状态与数据设计

为了支持持续倒计时，需要在当前答题状态基础上补充：

- 练习开始时间
- 设置开始时间的方法
- 页面加载时恢复开始时间的逻辑
- 当前浏览器中的本地草稿答案

推荐规则：

- 以 `sessionId` 为键保存本次练习开始时间
- 以 `sessionId` 为键保存本次练习的草稿答案
- 首次进入该练习时写入
- 同一个 `sessionId` 再次进入时直接复用开始时间和草稿答案
- 提交成功后清理该 `sessionId` 的计时记录
- 提交成功后同时清理该 `sessionId` 的本地草稿

这样可以保证：

- 刷新后仍能延续
- 不同练习不会串时间
- 提交后不会遗留旧计时状态
- 当前浏览器里的做题草稿可以延续

## 自动提交规则

当倒计时归零时：

1. 如果当前题已有选择，先保存当前答案
2. 读取所有已保存答案
3. 触发提交接口
4. 跳转到结果页

如果提交已经在进行中，则不重复触发。

## 测试与验证

实现后至少验证：

- 切题时正文区体积稳定
- 正文区明显比上一版更宽
- 正文超长时使用内部滚动，不再继续撑高页面
- 选项文本整体左对齐
- `Suivant` 按钮位于右下方
- 右侧倒计时能正常显示
- 刷新页面后剩余时间不会重置
- 刷新页面后已保存的草稿答案会自动回填
- 提交成功后倒计时停止
- 时间归零时会自动提交
- 最后一题提交逻辑仍然正常

## 不在本次范围

- 后端保存考试剩余时间
- 多设备同步同一套题的倒计时
- 暂停考试
- 倒计时告警音效
- 单独的监考模式

## 最终决策

本次答题页增强采用：

- 三段式答题页布局
- 更宽的正文主区域
- 固定高度且内部滚动的正文区域
- 左对齐的选项按钮内容
- 右下角 `Suivant` 主按钮
- 基于开始时间持续计算的 60 分钟倒计时
- 刷新后继续计时
- 刷新后恢复当前浏览器里的本地草稿答案
- 提交后停止计时
- 时间耗尽时自动提交
