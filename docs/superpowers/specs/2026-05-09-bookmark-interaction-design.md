# 收藏交互统一设计说明

## 背景

AllôTCF 当前有四处与题目收藏相关的入口：套题做题页、提交后的复盘页、错题复习页、收藏练习页。此前这些入口混用了文字按钮、底部工具栏按钮和题号角标，用户容易不确定“收藏”到底是一个题目动作、页面筛选，还是复习任务入口。

本次统一收藏交互，目标是让用户在任何题目场景里都能用同一种视觉语言理解收藏状态。

## 设计原则

收藏是题目级动作，不是页面级动作。

每道题只保留一个主要收藏入口：题目卡片或题目正文区域右上角的小书签。旧的圆角文字按钮 `收藏` / `已收藏` 不再作为主要入口出现，避免与页面底部操作、筛选操作混淆。

## 视觉规则

书签颜色使用页面中 `STATE` 字样接近的蓝绿色，当前实现色值为 `#0f766e`。

收藏状态分为两种：

- 未收藏：浅色空心书签，中间显示 `+`，提示用户可以加入收藏。
- 已收藏：同形状书签使用蓝绿色填满，不显示文字。

题号目录中的收藏标识只承担“提示这道题已收藏”的作用：

- 已收藏题：题号右上侧显示小号填充书签。
- 未收藏题：不显示任何角标。
- 目录角标不作为点击入口，避免遮挡题号或和题号跳转行为冲突。

## 页面规则

### 套题做题页

用户在正式作答过程中也可以收藏题目。

题目右上角显示书签按钮：

- 点击未收藏书签，会收藏当前题。
- 点击已收藏书签，会取消收藏当前题。
- 收藏状态来自当前用户账号，刷新或跨设备进入时应尽量保持一致。

### 复盘页

提交后原页进入复盘态，继续使用同一个题目右上角书签。

复盘态左侧目录仍用颜色表示答题结果：

- 绿色：回答正确。
- 红色：回答错误。
- 中性色：未作答。

如果题目已收藏，在对应题号右上侧叠加小号填充书签。

### 错题复习页

错题复习页仍允许收藏和取消收藏，因为用户在复习错题时可能判断某题需要长期关注。

列表态与单题复习队列都使用题目卡片右上角书签，不再使用文字按钮。

### 收藏练习页

收藏练习页展示所有已收藏题目，包括只收藏但没有答错过的题。

用户可以在收藏练习中取消收藏。取消后，该题会从当前收藏列表中移除；如果该题同时也是错题，它仍可在错题复习中出现。

## 移动端规则

手机端底部工具栏只保留导航类和页面类操作，例如目录、计时、结果、筛选、退出。

收藏不再放入底部工具栏，而是和桌面端一致，固定在当前题目卡片右上角。这样用户在手机和电脑上看到的是同一种题目级动作。

## 可访问性规则

虽然视觉上不显示 `收藏` / `已收藏` 文案，但按钮仍提供可访问名称：

- 未收藏按钮：`收藏本题`
- 已收藏按钮：`取消收藏本题`

这样既能保持界面简洁，也能支持测试、键盘访问和辅助技术识别。
