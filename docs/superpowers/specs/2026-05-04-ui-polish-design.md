# AllotCF 界面润色设计说明

> 状态：待实现
> 日期：2026-05-04

## 目标

为 `登录页`、`题库列表页`、`答题页`、`结果页` 建立统一的浅色视觉系统。

设计方向已经确认：

- 基调：浅色
- 气质：法语考试 / 书卷感
- 视觉骨架：`C · Revue`
- 色调修正：由暖棕改为偏绿色系

最终目标不是做成常见教育平台模板，而是做成：

- 像一本法语考试练习册与评论杂志的结合体
- 有高级纸面质感
- 但交互仍然清晰、高效、适合考试训练

## 核心视觉原则

### 1. Paper Editorial

整体背景使用浅纸面色，不使用纯白硬底。页面通过轻微的绿灰色层次、薄边框和低饱和模块分层，营造“印刷练习册”而不是“SaaS 控制台”的感觉。

### 2. Revue Structure

标题采用更强的版式感和更明确的层级，像法语期刊标题，而不是普通表单页标题。页面结构强调：

- 大标题
- 小标签 / 辅助说明
- 清晰模块分区
- 有节奏的留白

### 3. Quiet Efficiency

尽管视觉偏书卷气，但操作区必须保持高可用性：

- 按钮明显
- 当前题目状态明确
- 选中态高辨识
- 结果反馈一眼可读

不能为了风格牺牲考试流程效率。

### 4. Green-Toned Identity

主色从原来的暖棕改为绿色系，建议范围：

- 主强调色：鼠尾草绿 / 深森林绿
- 弱强调色：浅灰绿、纸面青灰
- 错误反馈：保留低饱和红色
- 成功反馈：偏自然植物绿

绿色应偏冷静、克制、印刷感，不做荧光感或互联网薄荷绿。

## 页面设计

### 登录页

定位为“进入练习册”的入口页，而不是典型后台登录页。

设计要求：

- 版心居中，但不要像默认表单卡片
- 标题更有刊物感，例如“登录你的练习册”
- 表单输入框保留简洁矩形结构，边框轻、背景浅
- 主按钮使用绿色主色，视觉上像“确认进入本期练习”
- 页脚链接（注册）弱化但清晰

页面应传达：

- 安静
- 专注
- 正式

### 题库列表页

定位为“题目期刊目录 / 练习册书架”。

设计要求：

- 顶部栏更像标题栏，而非工具导航栏
- 题库卡片像被编排过的条目，而不是纯功能卡片
- 每套题的标题权重高于按钮
- 元信息（题数、类型）使用低对比辅助文字
- “开始练习”按钮可以更像标签或章节入口按钮

页面应避免：

- 大面积默认灰框
- 过重阴影
- 纯产品后台式列表

### 答题页

这是整套产品最关键的页面，必须在“考试感”和“可做题效率”之间平衡。

设计要求：

- 顶部进度信息清晰但不过度抢眼
- 阅读材料区域像一张被排好的印刷页
- 题目标题像文章中的问题引导句
- 选项卡更像纸面标注块，而不是移动端大按钮
- 选中态使用绿色高亮与边框变化明确区分
- “下一题 / 提交”按钮保持主操作强度

页面应传达：

- 正在做一套正式阅读练习
- 信息有秩序
- 答题不紧张但高效

### 结果页

定位为“批改后的成绩页”。

设计要求：

- 分数区域像考试总结卡，而不是花哨成绩面板
- `correct / total` 是最强视觉焦点
- 正确率作为辅助信息
- 每题结果像批注条目
- 错误项使用低饱和红色提示正确答案
- 正确项使用低饱和绿色确认

页面应传达：

- 被认真批改
- 结果可信
- 可以继续下一套练习

## 组件与样式系统

建议统一以下基础设计令牌：

- `--bg-page`: 页面纸面背景
- `--bg-panel`: 卡片 / 模块背景
- `--color-text`: 主文字
- `--color-muted`: 辅助文字
- `--color-line`: 边框线
- `--color-accent`: 主绿色
- `--color-accent-soft`: 浅绿色背景
- `--color-success`: 正确反馈
- `--color-error`: 错误反馈

组件风格统一：

- 圆角存在，但克制，不走卡通风
- 边框优先于重阴影
- 模块间距大于当前版本
- 字体层级更鲜明

## 交互与状态

### 保留

- 当前已有的登录、注册、开始练习、答题、提交、查看结果流程
- 当前路由结构
- 当前 API 对接方式

### 优化

- 加载态视觉统一
- 空状态更有设计感
- 按钮禁用态更明确
- 选中态和 hover 态统一到绿色系统

## 测试与验证

实现后至少验证：

- 四页视觉语言一致
- 浅色主题在桌面和移动宽度下都可用
- 登录到结果页完整流程视觉没有断层
- 选项选中态与结果对错态辨识明确
- 前端测试和构建继续通过

## 不在本次范围

- 后台管理页
- 复杂动画系统
- 多主题切换
- 品牌 logo 设计
- 大规模信息架构调整

## 实施建议

按以下顺序实施：

1. 建立统一颜色、排版、间距变量
2. 改造登录 / 注册页作为风格起点
3. 改造题库列表页，建立卡片与标题系统
4. 改造答题页，处理核心交互视觉
5. 改造结果页，完成闭环
6. 浏览器联调整体一致性

## 最终决策

本次 UI polish 采用：

- `Revue` 风格骨架
- 浅色纸面背景
- 偏绿色的法语考试 / 书卷感
- 统一四页品牌语言
- 优先保证做题效率，其次追求高级质感
