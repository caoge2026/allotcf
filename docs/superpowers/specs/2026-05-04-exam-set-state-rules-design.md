# 题库卡片状态规则说明

> 状态：已实现
> 日期：2026-05-04

## 目标

明确题库列表页中每套题卡片的主状态与主按钮逻辑，避免在以下场景中出现用户预期不一致：

- 一套题从未开始
- 一套题存在未完成草稿
- 一套题已经完成并生成复盘
- 一套题完成后又重新练习
- 一套题同时存在完成记录与草稿
- 一套题存在多次完成记录

本说明只关注题库入口层的状态判断，不展开答题页内部交互细节。

## 状态定义

题库卡片主状态只保留 3 种：

1. `开始练习`
2. `继续作答`
3. `查看复盘`

这 3 种状态互斥，任意时刻一套题只能显示其中一种。

## 状态含义

### 1. 开始练习

适用条件：

- 当前套题没有已保存草稿
- 也没有已完成复盘记录

用户点击后：

- 新建一条练习会话
- 从第 1 题开始
- 倒计时从 `60:00` 开始

这是“全新开始”的默认入口。

### 2. 继续作答

适用条件：

- 当前套题存在已保存草稿
- 并且这份草稿比最近一次完成记录更新
- 或者当前套题根本还没有完成记录

用户点击后：

- 回到这份草稿对应的作答会话
- 恢复题号位置
- 恢复已选答案
- 恢复暂停时剩余时间

这是“最近一次有效状态仍然是未完成作答”的入口。

### 3. 查看复盘

适用条件：

- 当前套题存在至少一条完成记录
- 且当前不存在比最近完成记录更新的草稿

用户点击后：

- 进入最近一次完成会话对应的复盘态
- 不新建练习
- 右侧显示成绩摘要
- 页面不再继续倒计时

这是“最近一次有效状态已经完成”的入口。

## 状态优先级

当一套题同时存在完成记录和草稿时，不按“有没有完成过”直接判断，而是按“哪一个更新”判断。

优先级规则如下：

1. 如果存在比最近完成记录更新的草稿：显示 `继续作答`
2. 否则，如果存在完成记录：显示 `查看复盘`
3. 否则：显示 `开始练习`

也就是说，题库入口看的是“当前这套题最近一次有效学习状态是什么”。

## 草稿与完成记录的判定规则

### 草稿

草稿表示：

- 用户尚未正式提交
- 但本地已经保存了当前作答进度

草稿至少包含：

- 当前题号位置
- 已作答答案
- 暂停时剩余时间
- 草稿起始时间

### 完成记录

完成记录表示：

- 用户已经正式提交整套题
- 系统已经生成分数与 `CLB/NCLC`
- 这次提交可以被再次打开查看复盘

完成记录至少包含：

- 完成时间
- 最近一次完成对应的 `sessionId`
- 最近一次成绩摘要

## 多次完成记录

一套题可以被提交很多次，但题库入口层不同时暴露多条完成记录。

当前规则：

- 只认最近一次完成记录
- `查看复盘` 默认打开最近一次完成会话
- 题库卡片上显示的分数与 `CLB/NCLC` 也以最近一次完成为准

更早的完成记录视为历史记录，当前阶段不在题库卡片层展开。

## 典型路径说明

### 路径 1：从未开始

初始状态：

- 无草稿
- 无完成记录

题库显示：

- `开始练习`

### 路径 2：中途退出并保存

过程：

1. 用户进入一套题开始作答
2. 点击 `退出`
3. 选择 `保存当前进度并退出`

结果：

- 生成草稿
- 题库显示 `继续作答`
- 并显示当前进度摘要，例如 `11/39`

### 路径 3：正常提交

过程：

1. 用户完成作答并正式提交
2. 页面进入复盘态
3. 回到题库页

结果：

- 生成新的完成记录
- 清掉当前未完成草稿
- 题库显示 `查看复盘`

### 路径 4：完成后重新练习，再保存退出

过程：

1. 用户先完成一套题
2. 在复盘页点击 `重新练习`
3. 再次作答若干题
4. 点击 `退出`
5. 选择 `保存当前进度并退出`

结果：

- 新的未完成草稿晚于最近完成记录
- 题库显示 `继续作答`

这是因为“当前最近有效状态”已经变成了未完成重练。

### 路径 5：完成后重新练习，再不保存退出

过程：

1. 用户先完成一套题
2. 在复盘页点击 `重新练习`
3. 再次作答若干题
4. 点击 `退出`
5. 选择 `不保存并退出`

结果：

- 本次新的未完成重练不形成有效草稿
- 之前那条完成记录仍然保留
- 题库显示 `查看复盘`

这是因为“不保存并退出”不会覆盖旧复盘。

### 路径 6：继续作答后又不保存退出

过程：

1. 一套题本来已有已保存草稿，因此题库显示 `继续作答`
2. 用户点击 `继续作答`
3. 又做了若干题
4. 点击 `退出`
5. 选择 `不保存并退出`

结果：

- 不应删除原来的已保存草稿
- 应回退到进入本次会话前的那份基线草稿
- 题库仍显示 `继续作答`

这是因为用户放弃的是“这一次继续作答后新增的部分”，而不是更早已经明确保存过的那份进度。

## 按钮行为约定

### 题库页

- `开始练习`
  - 新建会话
- `继续作答`
  - 打开当前有效草稿
  - 可在其旁边提供次级按钮 `放弃进度`
- `查看复盘`
  - 打开最近一次完成复盘

#### `继续作答` 旁的 `放弃进度`

为了满足“用户在进入前就决定放弃当前草稿、重新从头做”的需求，允许在题库页 `继续作答` 主按钮旁增加一个次级按钮：

- `放弃进度`

当前状态：

- 已实现

推荐原因：

- 比放在答题页里更安全，降低误触风险
- 用户在进入前就能做出“保留进度 / 放弃进度”的判断
- 不会把答题页右侧控制区变得过重

建议行为：

1. 点击 `放弃进度`
2. 弹出确认框：`是否清空当前进度并重新开始？`
3. 用户确认后：
   - 删除当前套题草稿
   - 清掉当前未完成会话本地上下文
   - 新建一条新的练习会话
   - 从第 1 题开始
   - 倒计时回到 `60:00`

该按钮只在卡片主状态为 `继续作答` 时出现。

### 复盘页

复盘页右侧提供：

- `返回题库`
- `重新练习`

其中：

- `返回题库` 不改变当前题库状态
- `重新练习` 会创建新的作答会话

是否最终把题库状态切换为 `继续作答`，取决于用户之后是否保存这次重练进度。

## 题库文案约定

当前卡片摘要与徽标文案遵循：

- `开始练习`
  - 不显示进度或完成摘要
- `继续作答`
  - 显示 `上次进度 x/39`
  - 可在主按钮旁显示次级按钮 `放弃进度`
- `查看复盘`
  - 徽标显示 `已完成，可查看最近一次复盘`
  - 摘要显示 `上次得分 X 分，CLB/NCLC Y`

## 最终规则压缩版

可以把整个状态机压缩成一句话：

- 有比最近完成记录更新的草稿：`继续作答`
- 否则有完成记录：`查看复盘`
- 否则：`开始练习`

这就是当前题库入口状态的最终判定规则。
