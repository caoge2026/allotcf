# 艾宾浩斯错题复习计划设计说明

## 背景

AllôTCF 当前已经有阅读错题本、收藏练习、错误次数筛选、难度等级筛选和关键词搜索。错题本能帮助用户找到做错过的题，但还不能直接回答：

今天我应该优先复习哪些题？

艾宾浩斯错题复习计划的目标，是把错题本从“题目仓库”升级为“每日复习任务”。

## 设计原则

- 系统负责安排今天该复习什么，减少用户选择负担。
- 用户仍然可以进入全部错题，自主筛选和查找。
- `今日复习 / 全部错题` 是主视图，不和错误次数、难度、收藏、关键词混在同一筛选层级。
- 逾期题不会被藏在单独入口里，而是自动进入 `今日复习`。
- 错题本不通过“答对一次”直接删除题目，而是通过多轮复习逐步进入 `已掌握` 状态。

## 页面入口

错题本拆成两个主视图：

- `今日复习`
- `全部错题`

`今日复习` 是默认入口，展示系统认为现在应该复习的题。

`全部错题` 是完整错题库，保留现有筛选能力：

- 错误次数
- 难度等级
- 是否收藏
- 关键词

不单独设置 `逾期复习` 入口。原因是逾期题本身就比今日到期题更紧急，应该自动排在 `今日复习` 前面。

## 今日复习定义

`今日复习` 包含：

- 逾期未复习的题
- 今天到期的题

也就是：

```text
今日复习 = 逾期题 + 今日到期题
```

未到期题不进入 `今日复习`，只在 `全部错题` 中可见。

默认情况下，`今日复习` 只包含未掌握题。已经进入 `已掌握` 状态的题不会再作为今日任务打扰用户，除非用户主动切换到 `已掌握` 筛选查看。

## 今日复习概览

今日复习顶部提供轻量数据概览，用来帮助用户判断今天的复习压力。

展示字段：

- `逾期题`：当前筛选范围中，`next_review_at` 早于今天的未掌握题数量。
- `预计用时`：按每题约 45 秒估算，帮助用户快速判断今天是否适合完成。
- `今日已完成`：本次今日复习中，用户已经提交并答对的题目数量。
- `高频错题（>=5次）`：当前筛选范围中，错误次数大于等于 5 次的题目数量。

`今日已完成` 是用户体验层面的当日进度，不等同于套题成绩，也不进入 CLB/NCLC 计算。第一版用浏览器本地日期保存，刷新页面后仍应保留当天的完成数量。

如果存在逾期题，页面说明只保留引导文案：

```text
优先处理逾期题，再完成今天到期题。
```

逾期题数量只在概览卡中展示，避免同一信息重复出现。

## 复习间隔

第一版采用简化艾宾浩斯间隔：

- 第 1 次复习：1 天后
- 第 2 次复习：2 天后
- 第 3 次复习：4 天后
- 第 4 次复习：7 天后
- 第 5 次复习：15 天后
- 第 6 次及以后：30 天后

## 数据状态

每个用户对每道统一题目维护一份复习计划状态，挂在 `user_wrong_question` 上。

新增字段：

- `review_stage`：当前处于第几轮复习间隔。
- `next_review_at`：下一次应复习时间。
- `last_reviewed_at`：上次在错题复习队列中完成复习的时间。
- `last_review_result`：上次复习结果，例如 `CORRECT` 或 `WRONG`。

首次答错后的默认状态：

- `review_stage = 0`
- `next_review_at = 答错日期 + 1 天`
- `last_review_result = WRONG`

## 复习结果更新规则

用户在错题复习队列中选择选项后，系统立即判定正误并更新复习计划。

答对：

- `review_stage + 1`
- `last_reviewed_at = 当前时间`
- `last_review_result = CORRECT`
- `next_review_at = 当前日期 + 下一阶段间隔`

答错：

- `review_stage = max(0, review_stage - 1)`
- `last_reviewed_at = 当前时间`
- `last_review_result = WRONG`
- `next_review_at = 当前日期 + 1 天`
- 同时累计现有 `wrong_count`

为避免一次复习中重复计数，同一道题选择后不允许继续切换答案。

## 错题出口与掌握状态

错题本的出口不是物理删除错题，而是把题目从默认复习队列中沉淀到 `已掌握`。

掌握规则：

- `review_stage >= 4` 视为 `已掌握`。
- `review_stage < 4` 视为 `未掌握`。
- `未掌握` 是错题本和今日复习的默认状态。
- `已掌握` 题目默认不出现在今日复习和默认错题列表中。
- 如果已掌握题再次答错，阶段会下降；当 `review_stage` 低于 4 时，题目重新回到未掌握队列。

这样做的原因：

- 答对一次可能只是蒙对，不能立刻把题从错题本中移除。
- 多轮间隔复习后再退出默认队列，更符合长期记忆训练。
- 保留已掌握记录，可以让用户看到复习成果，也方便后续做掌握统计。

左侧筛选栏中的掌握状态只提供：

- `未掌握`
- `已掌握`

不提供 `全部 / 不限状态`。原因是页面顶部已经有 `今日复习 / 全部错题` 主入口，如果左侧再提供一个“全部”会让用户误以为存在两个层级的“全部错题”，增加理解成本。

## 今日复习排序

`今日复习` 默认排序：

1. 逾期题优先。
2. `next_review_at` 越早越靠前。
3. 同样到期时，错误次数越多越靠前。
4. 如果仍然相同，最近答错时间越近越靠前。

## 前端展示

题目卡片展示：

- 错误次数
- 难度等级
- 到期状态
- 收藏状态
- 来源套题
- 掌握状态

到期状态文案：

- `已逾期 3 天`
- `今天到期`
- `下次复习：5月12日`
- `待安排复习`

当题目为已掌握时，题目卡片展示 `已掌握` 徽标。

当今日没有到期或逾期题时，显示：

```text
今天没有必须复习的错题。你可以休息一下，也可以进入全部错题主动练习。
```

并提供 `查看全部错题` 入口。

当用户筛选 `已掌握` 且没有数据时，显示：

```text
暂时还没有已掌握的错题。
连续完成多轮复习并达到第 4 阶段后，题目会进入已掌握。继续完成今日复习，很快就会在这里看到你的成果。
```

这个空态需要同时做到两件事：

- 鼓励用户继续复习，而不是把空数据理解成错误。
- 明确告知 `已掌握` 的定义，减少用户困惑。

## 接口

新增今日复习列表：

```http
GET /api/review/today-wrong-questions
```

参数与错题列表保持一致：

- `type`
- `bookmarkedOnly`
- `minWrongCount`
- `difficultyLevels`
- `keyword`
- `masteryStatus`

`masteryStatus` 支持：

- `ACTIVE`：未掌握。
- `MASTERED`：已掌握。
- `ALL`：全部掌握状态，保留给接口和未来管理视图使用；当前产品界面不直接暴露。

新增错题复习单题结果提交：

```http
POST /api/review/wrong-questions/{canonicalQuestionId}/attempt
```

请求体：

```json
{
  "selectedAnswer": "A"
}
```

返回更新后的错题列表项。
