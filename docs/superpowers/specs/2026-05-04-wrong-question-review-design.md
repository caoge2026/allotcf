# 错题复习与科目导航设计

## 目标

在现有 `题库练习 -> 答题` 闭环之外，补上一条真正可复习的学习路径。

本次设计优先解决：

- 用户提交后，错误题目能自动沉淀下来
- 同一道题出现在不同套题中时，错误次数要累计
- 用户能按“最该复习”的顺序看到错题
- 提交后用户能在原答题页直接复盘，而不是跳到信息不足的结果页
- 导航结构要为后续加入 `听力 / 写作 / 口语` 预留空间

本次设计不追求一次性做成完整学习中心，而是先做“能复习”的 MVP。

## 设计结论

### 1. 导航结构

产品导航按“科目 -> 学习任务”两层组织。

一级导航使用顶部 `tab`：

- 阅读
- 听力

二级导航在当前科目下切换：

- 套题练习
- 错题复习

当前阶段：

- 阅读：
  - 套题练习：接现有题库页
  - 错题复习：新增错题页
- 听力：
  - 先显示“即将开放”

后续扩展：

- 阅读 | 听力 | 写作 | 口语
- 每一科下再显示适合该科的学习任务页签

采用顶部 `tab`，而不是首页大入口，原因是它更适合长期扩展为统一学习空间，避免以后科目增加后首页退化成纯分发页。

### 2. 错题本、收藏与收藏练习的关系

当前版本不同时做两个同级主入口。

保留：

- 主入口：错题复习
- 题目动作：收藏

暂不保留：

- 独立一级入口：收藏夹

原因：

- 错题复习是系统自动判断的“薄弱点”
- 收藏是用户主动标记的“重要题”
- 两者逻辑不同，但如果同时作为同级入口，当前阶段容易信息重复、增加理解成本

因此本次结构为：

- 阅读
  - 套题练习
  - 错题复习

收藏先作为题目标签与筛选条件存在，不单独占导航入口。

已增加 `收藏练习`，用于覆盖“只收藏但从未答错”的题目。

收藏练习与错题复习的边界：

- 错题复习：系统自动收录答错过的题
- 收藏练习：用户主动收藏过的题，无论是否答错过

这样可以避免把“只收藏但没答错”的题硬塞进错题本，也能让用户集中练习所有自己标记过的重要题。

推荐的未来结构：

- 阅读
  - 套题练习
  - 错题复习
  - 收藏练习

当前实现把 `收藏练习` 放在阅读科目的二级任务页签中，与 `套题练习`、`错题复习` 并列。

### 3. 同题归并规则

一道题可能出现在不同套题中。错题统计必须按“统一题目”聚合，而不是按“套题中的题目实例”聚合。

统一题目判定规则：

- `optionA + optionB + optionC + optionD + correctAnswer` 一致

满足以上条件，即视为同一道题。

例如：

- 用户在 `Serie 01` 中错了某题一次
- 又在 `Serie 03` 中错了同一道题一次

则错题复习中应显示为：

- 同一条题目
- `错误次数 = 2`

而不是两条不同记录各错一次。

### 4. 错题排序规则

错题复习默认排序：

1. `wrongCount` 降序
2. `lastWrongAt` 降序
3. `canonicalQuestionId` 或创建顺序升序

这样最常错、最近还在错的题会优先出现在前面。

### 5. 收藏能力的定位

收藏是题目级属性，当前服务于套题做题、复盘、错题复习与收藏练习。

当前阶段收藏的作用：

- 用户在套题做题过程中可以收藏 / 取消收藏当前题
- 用户在复盘模式下可以收藏题目
- 用户在错题复习页可以收藏 / 取消收藏
- 错题复习页支持筛选 `仅看已收藏`

收藏入口统一使用题目右上角的小书签，不再使用圆角文字按钮 `收藏` / `已收藏`。未收藏时显示浅色空心书签并带 `+` 提示；已收藏时书签使用蓝绿色填满。题号目录只在已收藏题右上侧显示小号填充书签，未收藏题不显示标识。

收藏练习的作用：

- 汇总所有已收藏题目
- 包含“答错且收藏”的题
- 也包含“只收藏但从未答错”的题
- 支持集中练习收藏题

当前阶段不做：

- 独立收藏夹页面
- 收藏题目的单独统计页

## 用户可见流程

### 套题练习

1. 用户进入 `阅读 -> 套题练习`
2. 完成一套题并提交
3. 当前答题页直接切换为复盘模式
4. 系统自动识别所有错误题
5. 错误题写入错题池，并按统一题目聚合

### 提交后的复盘模式

提交后不跳转到独立结果页，而是在当前答题页直接切换为“复盘模式”。

这样做的原因：

- 减少一次页面切换与额外点击
- 用户刚做完题，题目上下文仍然保留，复盘效率更高
- 现有答题页已经具备目录、正文、选项结构，天然适合改造成讲评视图
- 后续接入错题复习与讲解功能时，仍然围绕同一套题面展开

复盘模式下：

- 左侧目录用颜色区分正确与错误
- 中间继续显示原题题干、正文、选项
- 选项本身承担判分反馈
- 右侧计时卡停止倒计时，改为成绩摘要与后续动作
- 页面底部或正文下方预留讲解区

### 题库入口与复盘入口逻辑

为了减少用户重复判断，题库卡片只暴露当前最合理的主动作：

- 未开始：显示 `开始练习`
- 存在未完成草稿且尚未完成：显示 `继续作答`
- 已完成：显示 `查看复盘`

其中：

- `已完成` 状态优先级高于未完成草稿
- 用户点击 `查看复盘` 后，进入最近一次完成会话对应的复盘态
- 仅仅“查看过一次复盘”不会改变题库入口状态
- 已完成卡片的提示语放在徽标中，文案为 `已完成，可查看最近一次复盘`

### 复盘页中的按钮逻辑

复盘态右侧控制区不再显示 `提交` 和 `退出`，改为：

- `返回题库`
- `重新练习`

具体行为：

- `返回题库`
  - 直接返回题库列表页
  - 不改变这套题的“最近一次复盘”记录
- `重新练习`
  - 立即创建一条新的作答会话
  - 清空当前复盘态
  - 倒计时从 `60:00` 重新开始
  - 进入新的作答模式

如果用户在重新练习的新会话中又选择退出：

- `保存当前进度并退出`：回到题库页后显示 `继续作答`
- `不保存并退出`：只丢弃这次新的未完成会话，不影响旧的完成复盘
- 因为旧复盘仍存在，所以题库主入口继续显示 `查看复盘`

### 复盘模式中的判分表达

不再单独新增一块重复的“你的答案 / 正确答案”文本摘要。

改为由选项区域直接承担判分信息：

- 用户选对：
  - 该选项显示绿色正确态
- 用户选错：
  - 用户选择的错误选项显示红色错误态
  - 正确答案显示绿色正确态
- 用户未作答：
  - 正确答案显示绿色正确态
  - 其他选项保持普通态

题目级别只保留一行轻量状态提示：

- 回答正确
- 回答错误
- 本题未作答

新增动作：

- 收藏 / 取消收藏

对错与收藏的关系：

- 答错题：自动进入错题池
- 收藏题：由用户主动决定
- 一道题可以既是错题，又是收藏题
- 一道题也可以只是收藏题，但从未答错；这种题应进入收藏练习，而不是进入错题复习

### 讲解预留区

复盘模式中固定保留一个 `讲解` 区块，放在选项区之后。

当前阶段：

- 先显示占位文案，例如“讲解功能即将开放”

未来可扩展内容：

- 正文中暗示答案的关键句
- 关键词提示
- 选项排除思路
- 中文翻译
- 难句拆解

### 错题复习

用户进入 `阅读 -> 错题复习` 后，看到的是聚合后的统一题目列表，而不是按套题拆开的重复记录。

后续引入艾宾浩斯复习计划后，错题复习应拆成两个主视图：`今日复习` 和 `全部错题`。`今日复习` 包含逾期未复习题和今天到期题；`全部错题` 保留错误次数、难度等级、收藏和关键词等筛选能力。详细规则见 `docs/superpowers/specs/2026-05-09-ebbinghaus-wrong-question-review-design.md`。

每条题目至少展示：

- 题目主体
- 错误次数
- 最近一次答错时间
- 是否已收藏
- 出现过的套题来源

支持筛选：

- 全部错题
- 仅看已收藏

支持排序：

- 默认按错误次数优先

### 收藏练习

收藏练习用于集中复习用户主动标记过的题目。

收藏练习默认展示：

- 所有已收藏题
- 包含曾经答错过的收藏题
- 包含从未答错过、但用户认为重要或容易遗忘的收藏题

收藏练习不等同于错题复习：

- 错题复习默认都是错题，可筛 `仅看已收藏`
- 收藏练习默认都是收藏题，可筛 `只看做错过的收藏题`

`只看做错过的收藏题` 默认关闭。

打开后，只显示同时满足以下条件的题目：

- 当前用户已收藏
- 当前用户存在错题记录

该筛选不应命名为“同时也是错题”。推荐文案为：

- `只看做错过的收藏题`

原因是该文案更贴近用户语言，也能明确表达这是收藏练习页内部的收窄条件。

收藏练习与错题复习保持一致的复习队列体验：

- 列表态只负责浏览、筛选、查找、取消收藏和查看来源
- 列表态不暴露正确答案，不把选项作为作答按钮
- 列表顶部显示“已筛选出 X 题”和“开始复习当前结果”
- 点击后进入单题复习队列
- 队列态每次只显示一道题
- 点击选项后立即显示“回答正确 / 回答错误”
- 右下角使用 `Suivant / 完成复习` 进入下一题或结束
- 顶部保留“返回列表”

### 错题复习筛选栏

错题复习页新增左侧固定筛选栏，右侧保留错题卡片列表。

这样做的原因：

- 错题复习更像长期使用的复习工作台，而不是一次性浏览列表
- 筛选条件会长期存在，放在左侧比放在顶部更稳定
- 当前产品已经形成“左侧目录 / 右侧内容”的使用习惯，错题页继续沿用会更自然
- 当筛选项增加到错误次数、收藏、等级、关键词时，顶部空间会过于拥挤

页面布局调整为：

- 左侧：固定筛选栏
- 右侧：筛选结果行动条、错题卡片列表、单题复习队列

左侧筛选栏在桌面端固定于视口内，不随右侧列表滚动。移动端后续可折叠为顶部筛选抽屉，但不属于本次范围。

### 筛选结果与单题复习队列

错题复习页不应只把所有符合条件的题目铺满页面，否则用户虽然完成了筛选，仍然不知道应该从哪一道题开始。

因此右侧结果区采用两层结构：

- 默认显示筛选结果列表，用于浏览、查找、收藏和快速检查
- 列表顶部显示“已筛选出 X 题”和“开始复习当前结果”
- 点击“开始复习当前结果”后，进入单题复习队列
- 单题复习队列每次只显示一道题，顶部显示“第 N / X 题”
- 队列内提供“返回列表”和右下角 `Suivant / 完成复习`
- 用户点击选项后立即显示“回答正确 / 回答错误”，不再需要额外点击“提交”

该队列只使用当前筛选结果，不额外重新排序或重新请求数据。筛选条件负责决定复习范围，队列负责降低用户面对大量错题时的选择压力。

### 筛选条件定义

#### 1. 错误次数

错误次数采用门槛式筛选，而不是精确分桶。

提供 4 档：

- `至少错 10 次`
- `至少错 5 次`
- `至少错 3 次`
- `全部`

采用门槛式的原因：

- 用户更关心“哪些题反复出问题”
- 不需要在“只错 2 次”与“只错 3 次”之间来回切换
- 与当前默认排序“错误次数越多越靠前”一致

#### 2. 是否收藏

保留 `仅看已收藏` 开关。

规则：

- 关闭时显示全部符合条件的错题
- 打开时只显示当前用户已收藏的错题

#### 3. 难度等级

难度等级采用多选，而不是单选。

可选项：

- `A1`
- `A2`
- `B1`
- `B2`
- `C1`
- `C2`

采用多选的原因：

- 用户经常会希望一起看相邻难度，例如 `B1 + B2`
- 如果只能单选，会让复习切换过于频繁

#### 4. 关键词搜索

新增关键词输入框，输入时实时筛选。

搜索范围：

- 正文
- 题干
- 四个选项

匹配方式：

- 前后端都使用包含匹配
- 关键词为空时不过滤
- 命中的关键词在题干、正文、选项中使用统一的行内高亮样式标出
- 高亮只覆盖命中的词片段，不对整段正文或整项选项整体染色

采用实时筛选的原因：

- 比“输入后再点搜索按钮”更便捷
- 用户通常只记得一两个关键词，希望快速缩小范围

为了避免输入时反复整页闪烁，错题复习页在关键词变化时应保留当前列表内容，只在后台刷新筛选结果，而不是把整块内容替换成全页加载态。

### 难度等级映射规则

难度等级不是错题页的临时显示逻辑，而是每道题本身的属性。

也就是说：

- 不只是错题有等级
- 每一道阅读题都应映射到一个固定等级
- 错题复习页只是使用这个等级属性来筛选

当前阅读题先按题目分值映射：

- `A1 = 3`
- `A2 = 9`
- `B1 = 15`
- `B2 = 21`
- `C1 = 26`
- `C2 = 33`

这套映射应落到题目数据层，而不是只在错题页面现算。这里需要区分两层：

- 题目实例层：每道阅读题按自己所在题号段映射等级
- 统一题目层：如果同一道统一题目跨套出现在多个题号段，则取其出现过的最高等级

采用“最高等级”的原因：

- 错题复习按统一题目聚合展示
- 同一道题在不同套题里可能落在不同题号段
- 取最高等级更保守，也更符合“优先按更难版本复习”的心智

这样后续：

- 套题练习
- 复盘页
- 收藏能力
- 听力题目

都可以复用同一套难度等级字段。

### 筛选组合规则

多个筛选条件之间使用“同时满足”的逻辑：

- 错误次数门槛
- 是否收藏
- 难度等级多选
- 关键词搜索
- 掌握状态

例如：

- `至少错 5 次`
- `仅看已收藏`
- `B2 + C1`
- 关键词 `travaille`

表示只保留同时满足以上条件的错题。

### 掌握状态与错题出口

错题复习不采用“答对一次就删除”的规则。因为用户可能只是猜对，立即移出错题本会削弱复习效果。

当前规则：

- `review_stage >= 4` 视为 `已掌握`。
- `review_stage < 4` 视为 `未掌握`。
- 默认错题列表和今日复习只显示未掌握题。
- 已掌握题可以通过左侧 `已掌握` 筛选查看。
- 已掌握题再次答错后会降低阶段；低于第 4 阶段后重新回到未掌握队列。

左侧掌握状态筛选只保留：

- `未掌握`
- `已掌握`

不额外提供 `全部 / 不限状态`，因为页面顶部已经有 `今日复习 / 全部错题` 主视图，重复入口会让用户误以为存在两套“全部错题”逻辑。

### 默认行为

进入错题复习页时，默认状态为：

- 错误次数：`全部`
- 是否收藏：关闭
- 难度等级：全不选，表示不过滤
- 掌握状态：`未掌握`
- 关键词：空

默认排序保持不变：

1. 错误次数降序
2. 最近答错时间降序

## 数据模型设计

本次功能需要把“题目实例”与“统一题目”区分开。

### 1. 题目实例

现有 `question` 仍表示某个套题中的一道题。

它负责：

- 属于哪套题
- 在该套题中的题号
- 展示题干、材料、选项、答案

### 2. 统一题目

新增统一题目概念，例如：

- `canonical_question`

建议字段：

- `id`
- `type`
- `dedupe_key`
- `option_a`
- `option_b`
- `option_c`
- `option_d`
- `correct_answer`
- `created_at`

其中：

- `dedupe_key` 由 `optionA + optionB + optionC + optionD + correctAnswer` 规范化后生成

### 3. question 与 canonical_question 的关系

在 `question` 表中增加：

- `canonical_question_id`

这样多套题中的重复题都能指向同一个统一题目。

### 4. 用户错题统计

新增用户错题聚合表，例如：

- `user_wrong_question`

建议字段：

- `id`
- `user_id`
- `canonical_question_id`
- `wrong_count`
- `last_wrong_at`
- `last_user_answer`
- `created_at`
- `updated_at`

唯一约束：

- `user_id + canonical_question_id`

这样同一个用户对同一道统一题目只有一条累计记录。

### 5. 用户收藏

新增用户收藏表，例如：

- `user_question_bookmark`

建议字段：

- `id`
- `user_id`
- `canonical_question_id`
- `created_at`

唯一约束：

- `user_id + canonical_question_id`

## 后端行为设计

### 1. 导题阶段

在导题时为每道题生成 `dedupe_key`。

流程：

1. 规范化四个选项和正确答案
2. 生成 `dedupe_key`
3. 查找是否已有相同 `dedupe_key` 的 `canonical_question`
4. 若存在则复用
5. 若不存在则新建
6. `question` 记录关联 `canonical_question_id`

### 2. 提交判分后写入错题池

在练习提交完成后：

1. 找出所有错误题
2. 根据每道 `question` 的 `canonical_question_id`
3. 对当前用户执行 upsert：
   - 已存在：`wrong_count + 1`
   - 不存在：创建新记录
4. 更新：
   - `last_wrong_at`
   - `last_user_answer`

同时返回复盘模式所需数据，而不是只返回抽象分数摘要。

### 3. 收藏操作

新增收藏接口：

- 收藏某题
- 取消收藏某题

收藏目标不是 `question.id`，而是 `canonical_question_id`。

### 4. 错题复习接口

新增错题复习列表接口，返回聚合后的统一题目列表。

列表项至少包含：

- `canonicalQuestionId`
- 展示题面信息
- `wrongCount`
- `lastWrongAt`
- `isBookmarked`
- `sourceExamSets`

`sourceExamSets` 的每一项应包含套题标题与该题在原套题中的题号，格式为 `TCF 阅读真题 01 第 4 题`。如果原始题号缺失，后端用题目顺序兜底。

支持参数：

- 科目类型
- 是否仅看收藏
- 分页

### 5. 收藏练习接口

新增收藏练习列表接口，返回当前用户收藏过的统一题目列表。

列表项至少包含：

- `canonicalQuestionId`
- 展示题面信息
- `isBookmarked`
- `wrongCount`
- `lastWrongAt`
- `difficultyLevel`
- `sourceExamSets`

`sourceExamSets` 与错题复习接口保持一致，展示为 `套题标题 + 题号`。

支持参数：

- 科目类型
- 是否只看做错过的收藏题
- 难度等级
- 关键词
- 分页

其中 `只看做错过的收藏题` 对应的后端筛选语义是：

- `isBookmarked = true`
- 且当前用户存在 `user_wrong_question` 记录

## 前端页面设计

### 1. 顶部导航

新增科目切换与任务切换：

- 一级：阅读 | 听力
- 二级：套题练习 | 错题复习

阅读科目的二级任务包含：

- 套题练习
- 错题复习
- 收藏练习

当前阶段：

- 阅读可用
- 听力显示即将开放

### 2. 题库练习页

现有题库列表页迁移到：

- `阅读 -> 套题练习`

### 3. 答题页复盘态

答题页新增两种状态：

- 作答模式
- 复盘模式

提交成功后从作答模式切到复盘模式，不再跳转独立结果页。

#### 左侧目录

目录按钮状态增加：

- 正确：绿色
- 错误：红色
- 未作答：中性态
- 当前查看题：在上述状态基础上保留当前位置高亮

#### 中间内容区

保留与作答页相同的基本骨架：

- 题干
- 正文
- 四个选项

但交互从“可作答”切换为“可复盘”：

- 选项不可再修改
- 选项通过颜色直接表达判分
- 显示轻量状态文案
- 显示收藏动作
- 显示讲解占位区

#### 右侧信息卡

复盘模式下右侧卡片不再倒计时，改为静态成绩摘要：

- 正确题数 / 总题数
- 正确率
- 总分
- CLB/NCLC

并提供后续动作：

- 返回题库
- 重新练习

### 4. 错题复习页

页面内容包括：

- 标题区
- 筛选区
- 错题列表

每条错题卡片至少显示：

- 题目内容
- 错误次数
- 收藏状态
- 来源套题

列表态的错题卡片只负责浏览、查找、收藏和查看来源，不提供作答提交。进入单题复习队列后，题目选项才变为可选择状态。

单题复习队列中，用户点击选项后立即显示“回答正确”或“回答错误”，并用选项颜色标识正误；该行为不计算套题总分，不生成 CLB/NCLC 等级，也不写入正式练习成绩。

## 错误处理

- 若题目尚未建立 `canonical_question_id`，提交时不能静默失败，应返回明确错误
- 若收藏接口失败，前端提示“收藏未保存，请重试”
- 若错题复习列表为空，显示空态而不是空白页
- 若复盘模式数据返回不完整，页面应优先保证题面和选项可见，成绩摘要可降级为缺省提示

## 测试重点

### 后端

- 同一用户在两套题中错同一道统一题目时，`wrongCount` 会累计
- 只要 `optionA + optionB + optionC + optionD + correctAnswer` 一致，就能归并到同一个统一题目
- 收藏与取消收藏操作只作用于统一题目
- 错题列表按 `wrongCount` 与 `lastWrongAt` 排序正确
- 提交后返回的复盘数据包含判分状态、成绩摘要、收藏所需统一题目标识

### 前端

- 能在 `阅读 -> 套题练习` 和 `阅读 -> 错题复习` 间切换
- 提交后不跳转结果页，而是在答题页进入复盘模式
- 复盘模式左侧题号能正确显示红绿状态
- 复盘模式右侧计时停止并显示成绩摘要
- 复盘模式选项区能正确表达“选错 / 选对 / 未作答”
- 复盘模式可收藏 / 取消收藏
- 错题复习页能正确显示错误次数与收藏状态
- `仅看已收藏` 筛选正确
- 收藏练习页默认展示所有收藏题，包括从未答错过的收藏题
- 收藏练习页的 `只看做错过的收藏题` 筛选正确
- 错题复习页默认只展示未掌握错题
- `已掌握` 筛选能正确影响下方题目列表
- 已掌握无数据时显示解释性空态，告知达到第 4 阶段后进入已掌握
- 听力页签当前显示“即将开放”

## 结论

本次应优先实现“阅读科目下的错题复习 MVP”，并把未来扩展空间预留在导航和数据模型里。

核心原则：

- 导航按科目组织
- 提交后尽量不增加额外操作
- 复习按错题聚合
- 收藏先作为题目动作存在
- 同题统计以统一题目为准，而不是以套题实例为准
