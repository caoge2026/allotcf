# 阅读分数与 NCLC 区间设计说明

> 状态：待实现
> 日期：2026-05-04

## 目标

在每套阅读题提交后，不再只显示“答对多少题”，而是进一步计算：

- 本次阅读总分
- 该总分对应的 `NCLC` 区间

最终结果页需要让用户同时看到：

- 正确题数
- 阅读总分
- 所属 `NCLC` 区间

## 背景

当前系统的结果计算只统计：

- `totalCount`
- `correctCount`

这对练习闭环来说还不够，因为真实 TCF Canada 阅读训练更关注：

- 原始答题表现能换算成多少分
- 这个分数对应什么语言能力区间

因此需要在提交后引入正式的阅读计分规则和 `NCLC` 映射规则。

## 计分规则

本次阅读部分采用下面这套固定题号分值：

- `1-4`：每题 `3` 分
- `5-10`：每题 `9` 分
- `11-19`：每题 `15` 分
- `20-29`：每题 `21` 分
- `30-35`：每题 `26` 分
- `36-39`：每题 `33` 分

总分满分为 `699` 分。

只有答对的题才累计该题对应分值，答错或未作答不加分。

## NCLC 映射规则

阅读总分对应 `NCLC` 区间如下：

- `549-699` => `NCLC 10`
- `524-548` => `NCLC 9`
- `499-523` => `NCLC 8`
- `453-498` => `NCLC 7`
- `406-452` => `NCLC 6`
- `375-405` => `NCLC 5`
- `342-374` => `NCLC 4`
- `< 342` => `NCLC 4 以下`

本次范围只实现这张映射表，不扩展到写作、听力、口语。

## 设计结论

本次采用“后端统一计分，前端只展示”的方案。

也就是：

- 后端在提交练习时计算阅读总分
- 后端根据总分映射 `NCLC` 区间
- 前端结果页直接展示后端返回的分数和区间

这是当前最稳妥的方式，因为计分规则属于业务规则，应该集中在服务端维护，避免前后端各算一遍造成不一致。

## 后端设计

### 1. 结果 DTO 扩展

当前 `PracticeResultDto` 只有：

- `sessionId`
- `totalCount`
- `correctCount`
- `details`

本次需要补充：

- `score`
- `nclcLevelLabel`

其中：

- `score` 是阅读总分
- `nclcLevelLabel` 是类似 `NCLC 7`、`NCLC 4 以下` 这样的可展示文案

### 2. 计分时机

在 `submit(sessionId, request)` 中：

- 遍历用户答案
- 判断对错
- 如果正确，根据题号或顺序计算该题分值
- 累加得到总分
- 最终把总分和 `NCLC` 区间一起写入返回 DTO

在 `getResult(sessionId)` 中：

- 如果数据库中已有提交记录，也要能重新得出同样的总分与区间
- 保证刷新结果页或重新进入结果页时，展示一致

### 3. 计分基准

推荐以 `question.sequenceOrder` 为准，而不是依赖 `question_no` 文本格式。

原因是：

- 当前导入后的每套题都已经有稳定的 `sequenceOrder`
- `question_no` 可能存在 `1-1`、`10-1` 等文本格式差异
- 计分规则本质上是按题目在整套题中的顺序区间计算

## 前端设计

### 1. 类型扩展

前端 `PracticeResult` 类型需要补充：

- `score`
- `nclcLevelLabel`

### 2. 结果页展示

结果页在现有内容基础上增加：

- `总分`
- `NCLC 区间`

展示原则：

- `correct / total` 仍保留
- `总分` 成为与正确题数并列的重要信息
- `NCLC` 区间要一眼可读
- 不把区间说明做成很复杂的表格，当前只展示本次结果所属区间

## 测试与验证

实现后至少验证：

- 不同题号区间的题目答对时会累计正确分值
- 提交后返回总分
- 提交后返回正确的 `NCLC` 文案
- `getResult` 重新读取时，分数和区间与提交时一致
- 前端结果页能正常显示分数和 `NCLC`

## 不在本次范围

- 听力、写作、口语的区间计算
- 把分值规则存入数据库表
- 题目级别显示单题得分
- 历史成绩对比
- 成绩走势图

## 最终决策

本次阅读练习结果增强采用：

- 后端统一计算阅读总分
- 后端统一映射 `NCLC` 区间
- 前端结果页直接展示 `score` 和 `nclcLevelLabel`
- 低于 `342` 分时显示 `NCLC 4 以下`
