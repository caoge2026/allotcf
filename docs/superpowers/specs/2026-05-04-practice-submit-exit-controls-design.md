# 答题页提交与退出控制区设计说明

> 状态：已实现
> 日期：2026-05-04

## 目标

在答题页右侧倒计时信息区下方增加两个常驻操作按钮：

- `提交`
- `退出`

并统一整理当前答题页中的结束动作逻辑，避免“正文区底部提交”和“右侧提交”重复存在。

## 用户需求

当前答题页已经有：

- 左侧题号导航
- 中间正文与选项区
- 右侧倒计时信息区

但用户还需要两个更明确的控制动作：

- 可以在任意时刻主动提交当前整套答案
- 可以退出当前答题页，并保留本地草稿进度

同时，用户已经确认：

- `退出` 后返回 `题库列表页`
- 第 `39` 题底部不再保留额外的提交按钮

## 设计结论

本次采用下面这套方案：

- 右侧倒计时信息区下方增加两个常驻按钮：`提交` 和 `退出`
- 右侧控制区成为唯一的“结束动作区域”
- 中间正文底部按钮只保留顺序前进用途，统一使用 `Suivant`
- 到最后一题时，中间底部不再显示 `提交`
- 真正交卷只通过右侧 `提交` 完成

这是当前最一致的方案，因为它把“继续做题”和“结束本次作答”这两类动作彻底分开：

- 中间区域负责做题推进
- 右侧区域负责考试控制

## 页面结构

右侧信息区从当前的“倒计时 + 摘要”升级为“考试控制区”：

1. 倒计时
2. 题数与进度摘要
3. `提交` 按钮
4. `退出` 按钮

这样右侧栏的语义会非常明确：

- 看时间
- 看进度
- 决定交卷或退出

## 提交按钮设计

### 行为

点击 `提交` 时：

1. 先保存当前题已选答案
2. 读取当前整套答案
3. 调用现有提交接口
4. 停留在当前答题页并切换为复盘模式
5. 停止右侧倒计时
6. 在右侧显示正确题数、正确率、总分和 `CLB/NCLC`
7. 将本次完成结果保存为这套题最近一次可回看的复盘

### 作用范围

- 不要求当前必须处于最后一题
- 用户在任意题都可以主动提交

### 状态

- 提交过程中按钮进入禁用态
- 文案可切换为 `提交中...`

## 退出按钮设计

### 行为

点击 `退出` 时：

1. 打开页面内确认弹层
2. 标题文案：`是否保存当前进度并退出？`
3. 弹层内提供 3 个动作：
   - `留在本页`
   - `不保存并退出`
   - `保存当前进度并退出`
4. 如果用户选择 `保存当前进度并退出`：
   - 保存当前浏览器中的本地草稿答案
   - 保留当前套题的题号位置与暂停时剩余时间
   - 跳回 `题库列表页`
5. 如果用户选择 `不保存并退出`：
   - 删除这套题的本地草稿
   - 清掉当前未完成会话的本地上下文
   - 跳回 `题库列表页`
6. 如果用户选择 `留在本页`：
   - 关闭弹层
   - 继续停留在当前答题页

### 保存含义

这里的“保存当前进度”不等于正式交卷，而是：

- 保留本地草稿答案
- 保留当前套题的当前题号
- 保留当前套题的暂停时剩余时间
- 之后重新进入当前答题页时，可以继续作答

### 续做主键

为了满足“从题库重新进入同一套题仍能恢复”的需求，本地草稿不再只依赖 `sessionId`。

改为：

- 使用 `examSetId` 作为草稿主键
- `sessionId` 只负责当前页面刷新时找回所属套题

这样即使重新开始同一套题拿到新的 `sessionId`，也仍然能恢复：

- 已作答答案
- 当前停留题号
- 暂停时剩余时间

## 中间底部按钮设计

当前中间底部按钮已经承担顺序作答推进的职责。

本次调整后：

- 它只负责 `Suivant`
- 不再承担“提交整套答案”的职责
- 到最后一题时，不再显示额外的底部提交按钮

推荐做法：

- 非最后一题：显示 `Suivant`
- 最后一题：隐藏该按钮

这样能避免和右侧 `提交` 产生重复。

## 状态与数据设计

本次不增加新的后端接口，继续复用当前：

- 提交接口
- 本地草稿保存机制
- 本地倒计时恢复机制

需要补充的仅是页面层控制逻辑：

- 右侧提交入口触发已有提交流程，并在提交后切到复盘模式
- 右侧退出入口触发三按钮确认弹层
- 最后一题时隐藏中间底部推进按钮

同时约定：

- `退出` 只存在于作答态
- 一旦正式提交完成，页面进入复盘态，右侧控制区改为 `返回题库` 和 `重新练习`
- 如果题库卡片当前主状态为 `继续作答`，则题库页可额外提供次级动作 `放弃进度`
  - 该动作属于题库入口层，不属于答题页右侧控制区
  - 详细规则见 [2026-05-04-exam-set-state-rules-design.md](/Users/miao/my_project/allotcf/docs/superpowers/specs/2026-05-04-exam-set-state-rules-design.md)

## 测试与验证

实现后至少验证：

- 作答态右侧显示 `提交` 和 `退出`
- 点击 `提交` 会保存当前题并进入复盘模式
- 点击 `退出` 会出现三按钮确认弹层
- `保存当前进度并退出` 后返回题库列表页
- `不保存并退出` 后返回题库列表页且当前草稿被清除
- 自定义确认弹层中的“留在本页”会关闭弹层并继续停留
- 最后一题时中间底部不再出现额外提交按钮
- 非最后一题仍可用 `Suivant` 顺序前进

## 不在本次范围

- 提交前成绩预测
- 提交前确认弹窗
- 后端保存“未完成会话”状态

## 最终决策

本次答题页控制区增强采用：

- 右侧常驻 `提交` 和 `退出`
- `提交` 为唯一正式交卷入口，提交后原页切到复盘模式
- `退出` 使用三按钮确认弹层：
  - `留在本页`
  - `不保存并退出`
  - `保存当前进度并退出`
- 中间底部按钮只保留 `Suivant`
- 到第 `39` 题时，中间底部不再保留提交按钮
