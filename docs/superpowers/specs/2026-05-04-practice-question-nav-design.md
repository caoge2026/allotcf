# 答题页左侧题号导航设计说明

> 状态：待实现
> 日期：2026-05-04

## 目标

在答题页增加左侧题号导航区，让用户可以在当前套题内自由跳转到任意一道题，而不必只能依赖“下一题”顺序推进。

这次设计需要同时满足两个核心要求：

- 未作答的题也可以直接跳转
- 当用户已经在当前题选中答案、但还没有点击“下一题”时，点击左侧题号应自动保存当前选择

最终目标不是做成普通分页控件，而是让答题页更像一套正式练习册中的“题号目录”，既能快速浏览整套题，也能持续保持答题状态。

## 用户需求

当前答题页只支持顺序作答，存在几个体验问题：

- 用户无法快速回看前面题目
- 用户无法跳过暂时不会的题，先做后面的题
- 用户很难掌握自己整套题的完成情况
- 如果用户想切换题目，当前页上的已选答案没有独立的保存入口

因此需要把答题流从“单线性翻页”升级为“可自由跳转的会话式答题”。

## 设计结论

采用下面这套方案：

- 在桌面端答题页左侧增加固定题号导航栏
- 右侧保留现有阅读材料、题干、选项和主操作按钮
- 左侧显示整套题的题号列表，例如 `01 - 39`
- 当前题使用深绿色高亮
- 已作答题使用浅绿色背景标记
- 未作答题保持默认纸面样式
- 点击任意题号前，先自动保存当前题已选答案，再切换到目标题
- 原有“下一题”按钮保留，用于顺序刷题
- 统一在最后提交整套练习，不在跳转时提交

这是当前最适合的方案，因为它既满足用户明确提出的“左侧跳转”，又最大程度保留了现有答题主流程。

## 页面结构

答题页从当前的单列布局升级为双栏布局：

- 左栏：题号导航
- 右栏：当前题答题区

桌面端结构：

- 左栏宽度固定，适合作为目录区
- 右栏占主要内容宽度，保留阅读与作答体验

移动端结构：

- 不强行保留左侧栏
- 左侧导航区折叠到内容上方，转为横向或多列网格区
- 保证移动端仍然可以快速跳题，但不挤压正文阅读宽度

## 交互规则

### 1. 点击题号跳转

当用户点击左侧任意题号时：

1. 如果当前题存在已选答案，则自动保存到 `practiceStore`
2. 保存当前题的用时
3. 将 `currentIndex` 切换到目标题
4. 右侧区域刷新为对应题目内容
5. 如果目标题此前已经作答，自动回填该题之前保存的答案

### 2. 点击“下一题”

“下一题”继续保留现有定位，但行为要与左侧跳转一致：

- 先保存当前题答案和用时
- 再切换到下一题

这样可以保证：

- 顺序作答和自由跳转共用同一套状态逻辑
- 不会出现一种方式保存、另一种方式不保存的分裂体验

### 3. 最后一题

最后一题上：

- 主按钮显示“提交”
- 点击提交前仍然先保存当前题选择和用时
- 然后一次性提交整套答案

### 4. 已答题回填

如果用户跳回已经作答过的题：

- 页面要自动显示之前保存的选项
- 用户可以重新选择其他答案
- 再次跳转或提交时，以最新选择覆盖旧答案

## 状态设计

左侧题号需要至少呈现三种状态：

### 当前题

- 深绿色底或深绿色描边高亮
- 与其他题号有明显区分
- 让用户一眼知道当前所在位置

### 已作答题

- 浅绿色背景
- 保持较轻的视觉重量
- 表示该题已有保存记录

### 未作答题

- 默认纸面底色
- 保持可点击
- 不做禁用态

如果后续需要扩展，还可以加入：

- 当前题但未保存
- 已访问未作答

但这些不在本次范围内，本次先保持三态足够清晰。

## 数据与状态调整

当前 `practiceStore` 已具备：

- `questions`
- `currentIndex`
- `answers`
- `recordAnswer`
- `nextQuestion`

为了支持自由跳转，需要补充：

- 设置当前题索引的方法，例如 `goToQuestion(index)`
- 让跳转逻辑和“下一题”共用保存机制
- 在页面层根据 `answers` 判断每个题号是否已作答
- 在切换题目时，从 `answers` 回填当前题已保存答案

本次不改变后端接口，因为当前提交结构已经足够表达整套题答案。

## 视觉设计

新导航区要延续当前已经确认的浅色绿色书卷风：

- 左侧题号区像练习册页边目录
- 使用轻边框、低饱和底色、克制的高亮
- 不做蓝色系统按钮感
- 数字节奏整齐，题号采用两位数显示，例如 `01`、`02`
- 与右侧正文面板保持统一的纸面和边框语言

左栏不应喧宾夺主，但必须足够好点、好扫视。

## 测试与验证

实现后至少验证下面这些行为：

- 点击未作答题号可以直接跳转
- 点击题号前会自动保存当前已选答案
- 返回已作答题时可以看到之前保存的答案
- 修改已作答题答案后会覆盖旧答案
- 顺序点击“下一题”仍然正常
- 最后一题提交仍然正常
- 桌面端左侧题号可用
- 移动端布局不挤压正文

## 不在本次范围

- 标记“收藏题”或“待复查题”
- 倒计时功能
- 题号区搜索
- 多列分页目录切换
- 每题单独提交

## 最终决策

本次答题页导航改造采用：

- 左侧固定题号导航栏
- 当前题深绿色高亮
- 已作答题浅绿色标记
- 未作答题保持可点击默认态
- 点击题号时自动保存当前选择
- 支持自由跳转任意题
- 保留“下一题”和最终“提交”的原有主流程
