# AllotCF 登录页 Vicarius 风格重设计说明

> 状态：待实现
> 日期：2026-05-07

## 目标

为 `/login` 页面建立一套明显参考 [`vicarius.io`](https://www.vicarius.io/) 的视觉系统，但只迁移视觉语言，不迁移其安全产品营销语气。

本次改造的目标不是把登录页做成普通深色表单，也不是把整个产品改成企业安全官网，而是：

- 让登录页拥有更强的首屏冲击力
- 让页面从“常规登录卡片”升级为“产品首页级入口页”
- 保留当前中文学习产品的叙述方式
- 保留现有登录逻辑、注册入口、报错提示与跳转流程

最终效果应当是：

- 视觉上明显接近 `vicarius.io`
- 语义上仍然是一个法语考试练习产品
- 结构上像首屏 Hero + 登录控制台，而不是普通双栏后台登录页

## 已确认的设计决策

- 参考方向：`vicarius.io`
- 采用方案：`A. 近乎整页重构`
- 迁移范围：只改视觉，不改学习产品语气
- 页面范围：只改 `/login`
- 不扩散到 `/register`、题库页、答题页、结果页

## 核心视觉原则

### 1. Dark Product Hero

页面整体采用深色科技产品首屏语言。背景不使用纯黑，而是偏蓝灰的深色底，配合大面积模糊光晕、强对比标题和发光 CTA，形成类似 `vicarius.io` 的“平台入口”感。

登录页进入后应首先传达：

- 强烈的品牌气场
- 明确的主行动
- 产品能力被组织成信息模块

而不是先看到一个孤立表单。

### 2. High Contrast Typography

标题层级要显著放大，接近官网 Hero 的尺寸，而不是传统表单页标题。主标题承担页面视觉焦点，辅助说明使用更冷静的灰蓝文字，形成非常清晰的前后层次。

尽管视觉参考来自英文科技官网，中文排版仍需保证：

- 可读
- 稳定
- 不拥挤
- 保留学习产品的沉静气质

### 3. Luminous Interface

按钮、描边、状态标签和局部卡片边缘采用蓝紫发光系统，营造近未来产品面板质感。

但要克制：

- 发光只服务主层级
- 不让输入框或正文阅读被污染
- 不做过量霓虹噪声

### 4. Productized Study Narrative

尽管视觉像科技平台，内容表达仍然是“继续阅读训练”的叙事。页面里的卡片、标签和状态信息应展示学习产品价值，例如：

- 阅读套题
- 错题回看
- 结果记录
- 自动保存

不能出现偏安全厂商或企业 SaaS 的术语迁移。

## 页面结构

本次登录页不再是传统“双栏说明 + 表单卡片”的普通布局，而是重构为“首页式 Hero 入口页”。

### 顶层结构

建议结构如下：

1. 全屏或准全屏深色背景容器
2. 主 Hero 区
3. Hero 内左侧大标题与能力说明
4. Hero 内右侧悬浮登录控制台
5. Hero 下方补充一组产品化学习信息卡
6. 页面底部弱化版权

### 左侧 Hero 内容

左侧作为主视觉区，承载：

- 品牌标签，例如 `Lecture TCF`
- 超大中文标题
- 一段简短说明文字
- 2 到 4 个产品能力卡或状态卡

该区域的职责不是解释所有功能，而是建立强烈第一印象：

- 这是一个被认真设计过的学习入口
- 登录后会回到连续的训练流程中
- 产品有稳定、有组织的练习体系

### 右侧登录控制台

右侧是一张明显悬浮于背景上的登录模块，视觉上更接近产品控制面板：

- 深色半透明底
- 微发光描边
- 顶部状态标签
- 表单输入区
- 强渐变主按钮
- 注册入口和补充说明

这张卡片既是功能主体，也是视觉焦点之一。

### 下方信息模块

Hero 下方或左侧延展区域可增加学习产品信息卡，用于承接 `vicarius.io` 那种产品模块感。

内容建议保持学习语义，例如：

- 按题组顺序进入
- 自动保留最近练习状态
- 快速回到错题复盘
- 延续最近一次结果记录

这些卡片的作用是让页面更像产品首页，而不是补充营销文案。

## 视觉语言

### 背景

背景采用深蓝灰到近黑的渐变底，不使用当前浅色纸面系统。

需要加入以下氛围元素：

- 左上或中上区域的大面积蓝紫模糊光晕
- 局部青色冷高光
- 极轻的网格线、扫描线或科技纹理
- 大量留黑，保证标题和卡片有呼吸感

原则是接近 `vicarius.io` 的空间感，而不是做成赛博朋克海报。

### 配色

建议登录页专属色系：

- `--login-bg`: 深蓝黑背景
- `--login-bg-secondary`: 次级深色面
- `--login-text`: 高亮冷白正文
- `--login-muted`: 蓝灰辅助文案
- `--login-line`: 半透明冷色描边
- `--login-glow`: 蓝紫主光效
- `--login-glow-soft`: 稀释蓝紫光晕
- `--login-accent-cyan`: 辅助青色高光

主强调色以蓝紫为主，青色只做次级装饰，不与主按钮争抢。

### 排版

标题层级应明显大于当前版本：

- Hero 主标题：超大，成为页面第一视觉焦点
- 副标题：中等尺寸，控制在 2 到 3 行内
- 标签与状态文案：小号、字距更开、偏产品面板风格

中文内容应保持冷静、克制，不写成过度广告化的口号。

### 卡片与面板

卡片和登录控制台都采用以下共同语言：

- 深色或半透明深色背景
- 1px 半透明冷色描边
- 局部内阴影或外发光
- 较大圆角，但不能软糯
- 清晰的层级边界

应避免当前浅色圆润卡片的柔和杂志感。

## 关键组件设计

### 主标题区

主标题继续保留“继续你的 TCF 阅读准备”这一类学习入口语义，但排版上更像产品官网首屏：

- 更大尺寸
- 更紧的标题节奏
- 更强的视觉占比

### 输入框

输入框不再使用浅底矩形，而是：

- 深色输入底
- 冷色描边
- 蓝紫 focus 光效
- 更大横向尺寸
- 更一致的控制台感

必须保证：

- 占位文字可读
- 输入内容对比度充足
- 错误态有清晰区分

### CTA 按钮

主按钮是页面最亮的交互元素。

建议特征：

- 蓝紫渐变
- 明显光晕
- 较大高度
- hover 时轻微提亮或上浮

按钮文案可继续保持中文学习流程语气，例如“登录并继续”。

### 状态标签

例如“已自动保存”“本周练习入口”这类信息，应改为更像产品状态芯片：

- 深色底上的浅色字
- 蓝紫边缘高光
- 更紧凑、更硬朗

### 学习信息卡

信息卡保留学习场景含义，但视觉上靠近科技产品模块：

- 用短标题 + 一句说明
- 可加入弱编号、弱标签或关键词
- 不要做成温和教育卡片

## 响应式策略

桌面端采用强 Hero 结构：

- 左侧大内容
- 右侧登录控制台

平板与移动端调整为垂直堆叠：

1. 品牌标签
2. 大标题
3. 一句说明
4. 登录控制台
5. 学习信息卡

移动端要求：

- 标题仍有冲击力，但不能导致首屏完全被标题占满
- 表单控件保持大点击区域
- 光效适度减弱，避免造成阅读压力

## 保留与不变项

### 保留

- `login(email, password)` 调用方式
- `useUserStore` 登录态写入
- 登录成功跳转 `/exam-sets`
- 登录失败提示“邮箱或密码错误”
- 注册入口链接 `/register`

### 不变

- 不修改路由结构
- 不修改 API 层
- 不修改 store
- 不修改注册页的既有视觉
- 不修改其它页面的全局设计方向

## 不在本次范围

- 全站深色主题
- 注册页同步改版
- 题库列表页、答题页、结果页视觉统一到 Vicarius 风格
- 新增插画、视频或复杂 WebGL 背景
- 新增动画库
- 品牌重命名或文案体系重写

## 实现建议

建议按以下顺序实施：

1. 为登录页定义局部专属设计令牌和类名
2. 重写 `LoginPage.tsx` 的信息结构
3. 重写 `/login` 对应样式，限制在登录页作用域
4. 调整测试，锁定新结构与既有核心行为
5. 在浏览器中验证桌面与移动布局
6. 跑完整前端测试与构建

## 测试与验证

实现后至少验证：

- 登录页在桌面宽度下具有明显的 `vicarius.io` 风格首屏感
- 中文标题、说明和输入框在深色底上保持高可读性
- 登录按钮与状态芯片具备明确视觉主次
- 移动端堆叠后仍然优先展示登录流程
- 登录失败提示在深色面板中仍然清晰
- 登录页测试继续通过
- 全量前端测试通过
- `build` 通过

## 风险与注意事项

- 视觉如果还原过度，可能让 `/login` 与站内其它页面风格断层明显
- 深色背景与中文大标题如果处理不好，容易变得压迫或糊成一片
- 发光效果过重会损害输入表单可用性
- 登录页局部样式必须使用专属类名，避免污染注册页

## 最终决策

本次 `/login` 重设计采用：

- `vicarius.io` 风格作为强视觉参考
- `A. 近乎整页重构` 方案
- 深色科技产品首屏构图
- 大标题 + 悬浮登录控制台 + 学习信息模块
- 仅迁移视觉，不迁移安全产品语气
- 仅改登录页，不扩散到全站
