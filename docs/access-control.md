# 账户权限边界

正式网站只有 `admin@allotcf.com` 被授予 AUTHOR；普通注册账户始终为 LEARNER，注册请求中的 role 不会改变权限。

| 能力 | 管理员作者 | 普通学习账号 |
| --- | --- | --- |
| 浏览已发布笔记 | 可以 | 可以 |
| 创建、编辑、预览、发布、撤下笔记 | 可以 | 不可以 |
| 访问未发布草稿 | 仅自己的草稿 | 不可以 |
| 做题、收藏和错题复习 | 可以 | 可以 |
| 读取做题结果、保存进度、提交答案 | 仅自己的练习 | 仅自己的练习 |

公开笔记也允许未登录访客浏览。管理权限在后端验证，不依赖隐藏按钮。已发布版本和草稿分离，修改草稿不会自动影响读者。

练习接口从认证身份取得用户 ID，用 `sessionId + userId` 查询。不存在或不属于当前用户的记录统一返回 404，在任何成绩、答题或进度读写之前拒绝请求。作者权限不提供读取其他学习者记录的例外。

浏览器练习缓存按登录邮箱分区，仅用于界面恢复；真正的数据权限由后端控制。旧的未记录所有者的浏览器缓存不再读取，也不会转移给任意账户，服务器已保存的练习进度保持不变。

验证：38 项后端测试通过（含 8 项真实 MySQL 集成测试）；115 项前端测试通过；生产构建通过。数据库不需要结构变更。
