## Executive Summary

为 TCF Canada 移民申请人提供**精准、高效的真题词汇背诵平台**。用户群体为**零基础或 A1-A2 水平**、需在**一年内突击备考到 B2 水平**的加拿大移民申请人。法语在未来工作生活中用途有限，核心需求是**最短路径通过考试**。

### 独特之处

- **100% 真题词汇**：内容源自真实考试，按 A1-C2 分级
- **零弯路学习**：仅教授考试内容，最大化时间效率
- **科学记忆法**：间隔重复算法确保记忆效果持久
- **备考导向**：专为 TCF Canada 设计，区别于通用语言工具

## User Journeys

### 主要用户旅程 — 李明（备考移民申请人）

**开场场景**：
李明，32 岁，软件工程师，计划通过 TCF Canada 申请加拿大技术移民。法语水平 A1，距考试 8 个月。尝试过 Duolingo 和背单词 App，发现所学词汇考试不考，时间紧迫导致焦虑。

**上升行动**：
1. 朋友推荐"100% 真题词汇"平台
2. 注册后，系统根据 A1 水平推荐 A1-A2 级别真题词汇
3. 使用间隔重复系统背单词，每日 30 分钟

**高潮**：
- 1 周后，真题阅读练习正确率从 30% 提升至 50%
- 1 个月后，正确率稳定在 70%
- 考试当天，遇到大量平台背过的真题词汇

**结局**：
- 顺利通过 TCF Canada，达到 B2 水平
- 移民申请加分，成功获得邀请

## Domain-Specific Requirements

### 合规与监管

- **数据保护**：遵守中国《个人信息保护法》，数据存储于境内或合规境外服务器
- **内容版权**：真题词汇知识产权风险需评估，采用"词汇整理 + 原创释义"规避复制

### 技术约束

- **语言支持**：中文界面，法语词汇标注中文释义和音标
- **网络环境**：考虑中国大陆网络环境，确保加载速度（CDN 或国内服务器）

### 用户画像

- **目标用户**：中国成年人，母语中文
- **教育背景**：本科学位，有工作经历
- **学习动机**：加拿大移民申请，一年内从零基础/A1-A2 突击到 B2

### 领域风险

- **内容准确性**：建立词汇审核机制，确保 A1-C2 分级准确，释义正确
- **用户期望管理**：定位为"词汇辅助工具"，非"保过班"

## Innovation & Novel Patterns

### 核心理念

**"背单词就是练肌肉"** — 将语言学习定义为**可量化、可追踪、可优化**的训练过程，借鉴健身 App 模式。

### 创新功能

#### 1. 学习仪表盘（健身 Dashboard）

- **今日训练量**：已学习时长 / 目标时长
- **已掌握词汇**：今日新增 / 累计总数
- **记忆强度**："牢固"状态词汇百分比
- **连续学习天数**：🔥 连胜记录

#### 2. 训练计划生成器

用户输入考试日期后，系统自动生成倒推计划：
- 每日新词数量、复习数量、模考频率、预计完成时间
- 未完成任务时自动调整后续计划

#### 3. 个人记录系统

- 单日最多掌握词汇数、最长连续学习天数、最快复习速度、真题正确率峰值

#### 4. 进度可视化

- **词汇肌肉图**：按主题分类显示强弱项
- **遗忘曲线追踪**：显示即将遗忘的词汇
- **考试倒计时**：剩余天数和完成百分比

#### 5. 智能提醒

- 训练提醒、休息提醒、基于遗忘曲线的复习提醒

#### 6. 训练模式

- 热身模式、高强度训练、耐力训练、冲刺模式

### 市场背景与竞争优势

| 竞品 | 定位 | 差异 |
|---|---|---|
| Duolingo | 通用语言学习，游戏化 | 专注 TCF Canada 真题，效率导向 |
| Anki | 通用闪卡工具，需自建词库 | 预置真题词库 + 健身式追踪 |
| 其他背单词 App | 通用词库，无考试针对性 | 100% 真题词汇 + 备考训练计划 |

### 验证方法

1. **MVP 验证**：核心背单词功能 + 基础训练计划，观察留存率
2. **A/B 测试**：对比"健身模式"与"传统模式"的完成率和正确率提升
3. **用户反馈**：收集真实考试结果验证有效性

### 风险缓解

| 风险 | 缓解策略 |
|---|---|
| "健身模式"复杂 | 提供"简单模式"开关 |
| 训练计划不合理 | 允许手动调整每日目标 |
| 数据追踪增加焦虑 | 提供"隐藏进度"选项 |

## Web App Specific Requirements

### 项目类型概述

**SPA（单页应用）**，支持移动端浏览器、SEO 优化、实时功能，色盲用户无障碍访问。

### 技术架构

#### 1. SPA 架构

- **框架**：React/Vue.js，组件化开发和路由管理
- **状态管理**：Redux/Pinia 管理学习进度、词汇状态
- **路由**：客户端路由，学习流程无缝切换

#### 2. 移动端浏览器支持

- **响应式设计**：移动优先策略，手机/平板/桌面端适配
- **触摸交互**：滑动式学习（上滑下一个词，下滑复习）
- **PWA 支持**：可选离线学习和桌面图标

#### 3. SEO 优化

- **SSR**：Next.js/Nuxt.js 首屏渲染，提升搜索引擎收录
- **元数据**：动态生成标题、描述、关键词
- **结构化数据**：Schema.org 标记
- **公开页面**：首页、词汇示例页、备考指南页对搜索引擎友好

#### 4. 实时功能

- **WebSocket**：学习进度实时同步、在线状态显示
- **实时通知**：训练提醒、复习提醒、考试倒计时
- **协作功能**：未来支持学习搭子实时互动

#### 5. 无障碍访问

- **色彩对比度**：WCAG 2.1 AA 标准（至少 4.5:1）
- **非色彩提示**：正确/错误使用图标 + 颜色双重提示
- **色盲友好配色**：避免红绿搭配，使用蓝橙、蓝黄
- **字体大小可调**：支持自定义
- **键盘导航**：纯键盘操作学习流程

### 实现方案

| 需求 | 技术方案 |
|---|---|
| SPA 框架 | React + Next.js 或 Vue + Nuxt.js |
| 移动端适配 | Tailwind CSS + 响应式断点 |
| SEO | SSR/SSG + 动态元数据 |
| 实时通信 | WebSocket / Server-Sent Events |
| 无障碍 | WCAG 2.1 AA + 色盲友好配色 |
| 状态管理 | Redux Toolkit / Pinia |
| 部署 | Vercel / Netlify（支持 SSR） |

## Project Scoping & Phased Development

### MVP 策略

**方法**：问题求解型 MVP — 验证"真题词汇 + 训练计划 + 真题例句"能否有效提升正确率
**资源**：1-2 名全栈开发者 + 1 名内容运营

### Phase 1 - MVP（核心验证）

**核心旅程**：注册/登录 → 水平测试 → 背单词 → 查看进度

**必备功能**：
- **Word 文档解析与词汇/例句自动抽取**
- 完整真题词汇库（A1-C2 分级）
- 核心背单词功能（展示 + 记忆 + 测试 + 例句）
- 间隔重复算法
- 训练计划生成器
- 学习仪表盘
- 用户注册/登录
- 基础学习进度追踪
- 管理后台（审核、分级校正、发布）

### Phase 2 - 增长功能（Post-MVP）

**目标**：提升留存和商业化
- 模拟考试系统、个性化学习路径、个人记录系统
- 词汇肌肉图、训练模式选择、智能提醒
- 付费订阅系统、SEO 公开页面、移动端 PWA

### Phase 3 - 扩展（未来愿景）

**目标**：构建完整备考生态
- AI 辅助发音纠正、听力/阅读真题完整系统
- 写作/口语练习模块、用户社区、学习搭子
- 多语言支持、与移民顾问/培训机构合作

### 风险缓解

**技术风险**：
- Word 格式不统一 → 人工抽样验证解析准确性，建立标准模板
- 自动抽取准确率 → "程序抽取 + 人工审核"混合模式
- 间隔重复算法 → MVP 采用成熟开源算法（SM-2）
- 实时功能 → Phase 2 实现，MVP 使用定时同步

**市场风险**：
- 用户认可度 → 早期反馈和正确率数据验证
- 竞品模仿 → 建立真题内容壁垒和用户数据护城河

**资源风险**：
- 内容整理量大 → 优先 A1-B2 高频词汇及例句
- 开发资源有限 → 成熟技术栈（Next.js + PostgreSQL）

## Functional Requirements

### 用户管理
- FR1: 访客可以注册账户（邮箱/手机号）
- FR2: 用户可以登录/登出系统
- FR3: 用户可以重置密码
- FR4: 用户可以编辑个人资料（昵称、考试日期、当前水平）

### 内容管理（管理员）
- FR5: 管理员可以上传 Word 真题文档
- FR6: 系统可以自动从 Word 文档中抽取词汇、释义、音标和例句
- FR7: 管理员可以审核、校正自动抽取的内容
- FR8: 管理员可以为词汇分配难度等级（A1-C2）
- FR9: 管理员可以发布/下架词汇内容

### 学习核心
- FR10: 用户可以查看待学习的单词列表
- FR11: 用户可以查看单词详情（法语词、中文释义、音标、真题例句）
- FR12: 用户可以标记单词为"已掌握"或"需复习"
- FR13: 用户可以进行单词测试（选择正确释义/填空）
- FR14: 系统可以根据间隔重复算法自动安排复习计划
- FR15: 用户可以选择不同的训练模式（热身/高强度/耐力/冲刺）

### 训练计划
- FR16: 用户可以设置目标考试日期
- FR17: 系统可以根据考试日期和当前水平生成每日学习计划
- FR18: 用户可以查看每日学习任务（新词数量 + 复习数量）
- FR19: 系统可以在用户未完成当日任务时自动调整后续计划

### 学习追踪与仪表盘
- FR20: 用户可以查看学习仪表盘（今日训练量、连续天数、已掌握词汇数）
- FR21: 用户可以查看个人记录（单日最多掌握、最长连胜、最快复习速度）
- FR22: 用户可以查看词汇掌握进度（按主题/难度分类）
- FR23: 用户可以查看遗忘曲线预警（即将遗忘的词汇列表）
- FR24: 用户可以查看考试倒计时和完成百分比

### 通知与提醒
- FR25: 用户可以接收训练提醒（未完成当日任务时）
- FR26: 用户可以接收复习提醒（基于遗忘曲线的最佳复习时机）
- FR27: 用户可以接收休息提醒（连续学习过久时）

### 系统设置
- FR28: 用户可以调整界面字体大小
- FR29: 用户可以切换色盲友好模式
- FR30: 用户可以设置每日学习目标时长

## Non-Functional Requirements

### 性能
- NFR1: 单词卡片页面加载时间 **< 1 秒**
- NFR2: 学习进度同步延迟 **< 3 秒**
- NFR3: 100 并发用户时，页面响应时间 **< 2 秒**

### 安全
- NFR4: 所有用户数据（邮箱、手机号、学习记录）**加密存储**
- NFR5: 密码使用 **bcrypt 或同等强度哈希算法**存储
- NFR6: 防止爬虫抓取真题内容（请求频率限制、验证码机制）
- NFR7: 所有数据传输使用 **HTTPS/TLS 1.2+**

### 可扩展性
- NFR8: 系统支持 **300+ 并发用户**
- NFR9: 支持突发流量自动扩容，**3 分钟内完成**
- NFR10: 数据库支持 **10 万+ 用户**规模，性能下降 < 10%

### 无障碍
- NFR11: 界面符合 **WCAG 2.1 AA** 色彩对比度标准（至少 4.5:1）
- NFR12: 提供色盲友好配色方案（避免红绿搭配）
- NFR13: 支持纯键盘导航完成核心学习流程

### 可靠性
- NFR14: 学习数据 **零丢失**，实施每日自动备份
- NFR15: 系统可用性 **≥ 99.5%**（每月停机时间 < 3.6 小时）
- NFR16: 维护窗口安排在 **每月凌晨 2:00-4:00**
